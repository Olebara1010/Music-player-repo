# 🎵 Music Player

A desktop music player built with Python, using Tkinter for the GUI and Pygame for audio playback.

## Features
- Play, pause, unpause, and stop controls
- Scrollable playlist loaded dynamically from a local music folder
- Simple, clean desktop interface

## Tech Stack
Python · Tkinter · Pygame

## How to Run
1. Clone the repo
2. Install dependencies: `pip install pygame`
3. Make sure your song files are in the `music` folder next to the script
4. Run: `python Musicplayer.py`
